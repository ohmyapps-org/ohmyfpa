## Visual direction

The page follows the OhMy product family and the diagram language requested in the brief: a dark technical canvas, restrained cyan-teal accents, thin graph lines, compact cards and a central map that connects five function categories to one analysis. The map is an explanatory visualization, not a source of calculation truth.
